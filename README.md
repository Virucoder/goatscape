# Goatscape

Goatscape is a small 2D dungeon puzzle game where you play as a goat and try to escape before time runs out. Explore the dungeon, solve puzzles, and find your way to freedom!

## Features

- Play as a goat
- Explore a small dungeon
- Solve puzzles to progress
- Race against the timer
- Windows and Web exports

## Technologies

- **Godot Engine**
- **GDScript**
- **GitHub Pages** — Web version hosting

## Play the Game

- **Web version:** [Play Goatscape](https://virucoder.github.io/goatscape/)
- **Windows version:** See the [Releases](https://github.com/Virucoder/goatscape/releases/tag/v1.0.0) page.

> Note: The Web version is available once GitHub Pages is configured correctly.
